##  Brief Course Description
This course introduces the fundamental concepts of Object-Oriented Programming (OOP) using Java. Throughout the semester, students learn to design and implement Java applications using core OOP principles such as classes, objects, encapsulation, inheritance, polymorphism, and abstraction. The course also covers essential Java libraries for file handling, collections, and building graphical user interfaces (GUIs).
